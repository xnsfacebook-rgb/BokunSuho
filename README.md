# 복운수호 — 한국 사주·운세 블로그

한국 사주팔자, 띠별 운세, 오행, 궁합, 점괘를 전하는 운세 블로그입니다. 매일의 운세와 행운의 아이템(상점)을 함께 운영합니다.

- **사이트:** https://bokunsuho.xnsfacebook.workers.dev (Cloudflare Pages, main 브랜치 자동 배포)
- **유튜브:** [길운 안내서](https://www.youtube.com/@길운_안내서)

## 구조

- `public/index.html` — 블로그 홈페이지 (오늘의 띠별 운세 위젯, 최신 글, 띠별 운세 바로가기, 운세 도구, 상점)
- `public/blog.css`, `public/blog.js` — 블로그 스타일·위젯
- `public/posts/` — 글 6편 (사주 기초, 2027년 띠별 운세, 오행, 띠 궁합, 행운의 색, 점괘)
- `public/shop.html`, `public/shop.css`, `public/shop.js` — 상점 (31개 상품, AliExpress 어필리에이트)
- `public/auth.js` — Google 로그인 (Google Identity Services, Client ID는 복운수호 전용)
