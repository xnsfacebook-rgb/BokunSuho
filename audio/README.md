# 배경 음악 폴더

이 폴더에 배경으로 쓰고 싶은 음악 파일(`.mp3`, `.wav`, `.ogg`, `.m4a`)을 넣으세요.
서버를 다시 시작하면 설정 창의 "배경 음악" 목록에 자동으로 나타납니다.

- 파일이 없어도 괜찮습니다 — "🪷 범종 명상음 (자동 생성)"이 기본으로 제공됩니다.
- 파일명은 한국어로 지어도 됩니다. (예: `명상음악.mp3`)

# Thư mục nhạc nền

Thả file nhạc (`.mp3`, `.wav`, `.ogg`, `.m4a`) vào đây, restart server là
nó hiện trong danh sách "배경 음악" ở cửa sổ cài đặt.

- Không có file cũng chạy bình thường — mặc định có "🪷 범종 명상음 (tự sinh)".
